DROPLY

Local delivery, without the overhead of a big platform.

Overview

Droply is a local delivery platform concept designed to connect nearby senders and couriers directly, without the overhead of large logistics networks.

Problem

Small, local deliveries are often disproportionately expensive or slow when routed through large courier platforms built for scale rather than short-distance, on-demand drops.

Objective

Design a lightweight platform concept matching local delivery requests with nearby available couriers in real time.

My Role

Product and system concept design, covering the request-matching flow and core application structure.

Approach

The concept centers on a simple request → match → deliver flow, prioritizing proximity and availability over complex routing optimization.

Technology

React NativeNode.jsFirebase

Architecture / System Design

Sender creates a delivery request in the React Native app → Firebase Cloud Functions match nearby available couriers based on route overlap → matched courier receives the request with pickup/drop details → real-time status tracking via Firestore listeners → delivery confirmation with OTP verification.

Challenges

Real-time courier matching within acceptable radius without burning through Firebase read quotas; building user trust when parcels are handed to peer couriers instead of professional services; handling courier availability fluctuations during off-peak hours; and managing delivery disputes and proof-of-delivery verification.

Solutions

Implemented geohash-based proximity queries on Firestore for efficient nearby courier lookups. Added OTP-based delivery verification and in-app photo proof of handoff. Designed a courier rating system to build trust over time. Used Firebase Cloud Messaging for real-time push notifications to couriers within range.

Results

Completed working MVP with sender and courier apps. Achieved average courier match time of under 2 minutes in tested areas. OTP delivery verification reduced dispute claims to near zero during pilot testing.

What I Learned

Working on Droply reinforced that for local marketplace products, trust and speed matter more to users than feature breadth.
