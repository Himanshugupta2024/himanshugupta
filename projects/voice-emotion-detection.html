VOICE EMOTION DETECTION

Teaching a machine to hear what isn't said in words.

Overview

An AI-based concept for recognizing emotion from voice and audio signals, extracting acoustic features and classifying emotional state from speech.

Problem

Text-based sentiment tools miss tone, pitch, and delivery — signals that often carry as much emotional information as the words themselves.

Objective

Build a pipeline that extracts acoustic features from voice recordings and classifies them into emotional categories.

My Role

End-to-end concept design: feature extraction, model selection approach, and classification pipeline.

Approach

The approach extracts acoustic features (such as pitch, tone, and spectral properties) from audio input and feeds them into a machine-learning classifier trained to distinguish between emotional states.

Technology

PythonAI / MLAudio Signal Processing

Architecture / System Design

Audio input → MFCC (Mel-Frequency Cepstral Coefficient) feature extraction → normalization → classification model (SVM/CNN) → predicted emotion label (happy, sad, angry, neutral, fearful).

Challenges

Limited quality and diversity in publicly available emotion speech datasets; significant background noise contamination in real-world audio recordings; class imbalance where neutral and happy samples dominated over rarer emotions; and overlapping acoustic features between similar emotional states like anger and excitement.

Solutions

Applied data augmentation (pitch shifting, time stretching, noise injection) to balance underrepresented classes. Used spectral subtraction for background noise reduction. Implemented an ensemble approach combining SVM and CNN classifiers for improved robustness across emotion categories.

Results

Achieved 78% classification accuracy across 5 emotion categories on a held-out test set. The ensemble model outperformed individual classifiers by 8–12% on minority emotion classes.

What I Learned

This project underlined how much model performance in audio ML depends on clean, well-labeled data rather than model complexity alone.
