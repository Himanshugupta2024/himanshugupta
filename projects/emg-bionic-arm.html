BIONIC ARM USING EMG SENSORS

Turning muscle signals into motion.

Overview

An EMG-based control system using MyoWare sensors and a Raspberry Pi Pico for real-time, muscle-driven servo actuation of a robotic arm. Patent filed.

The Problem

Prosthetic and assistive arm systems need an intuitive way to translate a user's intended movement into robotic motion without complex manual controls.

The Idea

Capture EMG (electromyography) signals from the forearm using MyoWare sensors, process them on a Raspberry Pi Pico, and map them to real-time servo actuation.

My Role

End-to-end system design: EMG signal acquisition, ADC/DAC signal conditioning on the Raspberry Pi Pico, and the servo control logic.

Technology

MyoWare EMG SensorsRaspberry Pi PicoADC/DACServo ActuationC

Design / Architecture

MyoWare surface electrodes capture muscle signal activity, which is conditioned and read by the Raspberry Pi Pico's ADC. Thresholded signal profiles are mapped to servo actuation commands. The signal flow runs: EMG electrode → analog conditioning → Pico ADC → threshold classification → PWM servo control.

Implementation

Raw EMG signals are filtered and thresholded before being mapped to specific arm/gripper movements, driving the servo motors in real time.

Challenges

High-frequency noise contamination from power lines and nearby electronics affecting EMG signal quality; inconsistent electrode placement leading to variable signal amplitudes between sessions; servo response latency creating a disconnect between user intent and arm movement; and calibrating threshold values for different users with varying muscle strengths.

Result

Achieved reliable grip and release control with ~200ms response latency. Patent application filed for the EMG-driven prosthetic actuation approach. Demonstrated 3 distinct gesture classifications (open, close, pinch) with 85%+ accuracy during live testing.

Learnings

This project deepened my understanding of biosignal noise handling — clean signal acquisition matters as much as the control logic built on top of it.
